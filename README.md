# Bind

Git-backed web apps.

https://bind.0data.app

## Shortcuts

See [Codebase](https://bind.0data.app/codebase/) for a more in-depth development guide.

### Install

```sh
npm i
```

### Run

```sh
npm start
```

### Test

```sh
npm run test:unit
```

```sh
npm run test:ui
```

### Deploy

```sh
npm run build
```
